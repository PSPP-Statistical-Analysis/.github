- **Not Bayesian GUI And Not A Graph Brand:** Bayes factors and journal axes are other products.

## What Is PSPP

PSPP is a GNU statistics program that speaks the SPSS command dialect. Analysts who already coded a questionnaire open PSPP statistical analysis to run frequencies and regressions from a syntax they can archive. PSPP syntax file is the script. PSPP descriptive stats is the usual first output. PSPP survey table is the data view.

JASP and jamovi hide syntax behind menus (jamovi can show R). Statgraphics speaks quality engineering. MedCalc speaks clinic. PSPP speaks “DATA LIST, FREQUENCIES, REGRESSION” on a file you coded. It is not a complete clone of every SPSS module, and you should not pretend it is.

Analyze datasets you collected or were given permission to process. Keep syntax with the codebook. Do not paste licensed SPSS sample data into a public repo if the license forbids it.

## Starting with PSPP

Prerequisites: A PC you administer and a coded table you are allowed to analyze.

1. **Prepare:** Check variable names and missing codes against the codebook you keep.
2. **Configure:** Open PSPP survey table and start a PSPP syntax file named after that wave.
3. **Test:** Run PSPP descriptive stats on a few variables and match a hand tally.
4. **Refine:** Add recodes and labels in syntax, not only in the GUI, so the pass is repeatable.
5. **Apply:** Run the confirmatory PSPP statistical analysis the protocol named.
6. **Maintain:** Archive syntax with the data, and strip identifiers before any teaching copy.

## Best Uses

- **Questionnaire Wave You Coded:** PSPP syntax file for that year.
- **Office Staff Who Already Know SPSS Commands:** PSPP statistical analysis on files you administer.
- **Course That Teaches Syntax:** Public or licensed teaching data only.
- **Not A Bayes-First GUI:** Use JASP.
- **Not A Spreadsheet-On-The-Left GUI:** Use jamovi.
- **Not Clinical ROC:** Use MedCalc.
- **One Syntax Per Wave:** Mixing years hides PSPP survey table history.
- **Comments In The Syntax:** PSPP descriptive stats should cite the instrument version.
- **Do Not Claim Full SPSS Modules:** If a procedure is missing, say so in the report you write.
- **Value Labels From The Instrument:** PSPP survey table should match the paper questionnaire you keep.
- **Missing Codes Declared In Syntax:** PSPP syntax file before PSPP descriptive stats, not after a surprise N.
